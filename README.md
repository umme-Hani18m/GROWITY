# GROWITY 🌱

**A platform built to connect, support, and empower children through communities that care.**

GROWITY is a web platform designed to bring children, parents, NGOs, and support staff together in one place. It aims to make access to support, resources, volunteering, and essential services simpler and more accessible.

### What GROWITY offers
- **For Children:** A dedicated space to access resources, support, and assistance.
- **For Parents:** Tools to stay informed and connected with available support.
- **For NGOs:** Workspaces to manage volunteering, activities, and community initiatives.
- **For Staff:** Tools for coordination, reporting, and managing support workflows.

### Tech Stack
- **Frontend:** Next.js 16, React 19, TypeScript
- **Styling:** Tailwind CSS 4
- **Backend & Database:** Supabase
- **Authentication:** Supabase Auth
- **Localization:** next-intl (English & Hindi)
- **Validation:** Zod
